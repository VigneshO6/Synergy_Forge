# Onion Grading System

An AI-powered **Onion Grading System** that uses image processing and computer vision to analyze onion images and classify their quality. The system detects visible conditions such as healthy, defective, damaged, rotten, and sprouted onions, helping improve quality assessment and smart procurement.

### Key Features

* AI-based onion quality classification
* Image processing and computer vision
* Healthy, defective, and sprouted/rotten grading
* Mobile-based image capture and upload
* Automated quality reports
* QR-based batch tracking
* Smart procurement support

### Technology

**Python | OpenCV | TensorFlow/Keras | Ultralytics | Flutter**
